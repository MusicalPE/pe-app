1설치 — 사본 만들기, 5분

프로그램 본체는 제가 관리하는 라이브러리에 있고, 선생님 시트에는 껍데기 스크립트(Code.gs) 한 장만 들어갑니다. 그 껍데기와 라이브러리 연결이 이미 되어 있는 견본 시트를 사본으로 받으면 되니, 파일을 붙여 넣거나 스크립트 ID 를 칠 일이 없습니다. 초등학교든 중학교든 설치 방법은 같습니다. (이미 쓰고 있는 학교는 11장 "새 버전 적용"만 보면 됩니다.)

  1. 견본 시트 링크를 열고 사본 만들기를 누릅니다. (선생님 구글 계정으로 로그인된 상태에서)
    https://docs.google.com/spreadsheets/d/1iyR4cNB6RvOIOdqUHLVmCqZC2Rp6E0fOOJ5P7jc3wxU/copy
    사본이 열리면 왼쪽 위 파일 이름이 "… 견본의 사본" 으로 되어 있습니다. 이름을 클릭해 "의 사본"을 지우고 "햇살초 체육교사 보조 프로그램"처럼 학교 이름으로 바꿔 두세요. (안 바꿔도 동작에는 문제 없고, 사본은 선생님 드라이브에 선생님만 보는 파일로 만들어집니다.)
  2. 메뉴 확장 프로그램 → Apps Script → 오른쪽 위 배포 → 새 배포 → 유형 선택 ⚙ → 웹 앱 → 실행 주체 나 · 액세스 권한 모든 사용자 → 배포 → 액세스 승인 → 계정 선택 → "Google에서 확인하지 않은 앱" 화면이면 고급 → (프로젝트 이름)(으)로 이동 → 허용. (처음 설치할 때만 "새 배포"입니다. 이후 업데이트는 11장처럼 "배포 관리 → 새 버전"으로 하세요.)
  3. 나온 웹 앱 URL 을 복사해 브라우저에서 엽니다. 첫 접속 때 시트(설정·학생·안내·모듈별 시트)가 자동으로 만들어지느라 처음 한 번은 한참(30초 안팎) 걸립니다 — 흰 화면이어도 새로 고치지 말고 기다리세요. 교사 비밀번호 초기값 1234. 로그인 → 설정 → 화면 방식 → "새 화면" 으로 바꾸고 저장하면(권장) 같은 주소로 들어와도 GitHub 새 화면이 열리고(3장), 앱처럼 설치하고 화면 수정이 저절로 반영됩니다.
팁 · 주소는 두 가지같은 주소인데 뒤에 ?page=teacher 를 붙이면 선생님 탭이 먼저 열립니다. 태블릿에는 그냥 주소를, 선생님 컴퓨터에는 ?page=teacher 붙은 주소를 즐겨찾기하세요. 설정 → "접속 주소"에 둘 다, 그리고 학생용 QR이 나옵니다.
주의 · 승인 화면이 무섭게 생겼어요"확인되지 않은 앱"은 구글 심사를 받지 않은 개인 스크립트라는 뜻입니다. 시트·드라이브·문서 권한은 선생님 시트에 쓰고 사진을 드라이브에 올리기 위한 것이고, 선생님 계정 안에서만 동작합니다.
링크 없이 직접 설치하려면sheets.new 로 새 시트 → 확장 프로그램 → Apps Script → 기본 Code.gs 의 내용을 지우고 첨부 shell/Code.gs 를 붙여 넣기 → 왼쪽 "라이브러리" + → 스크립트 ID 1lCxSywFMSoGbnlymVfsRzEvBeweAXKVCjhigTMwpKlSC-lRGSwpR7QxT → 조회 → 버전은 가장 큰 숫자 → 식별자 PE → 추가 → 그다음은 위 2번부터 같습니다. 견본 시트는 이 과정을 미리 해 둔 것일 뿐이라 결과는 똑같습니다.

학생 명단 넣기

명렬 붙여넣기로 반마다 넣습니다. 한 줄에 번호 이름 성별. 엑셀·나이스에서 복사한 탭 구분도 그대로 되고 성별은 빼도 됩니다. 학생마다 바뀌지 않는 학생ID가 붙고 학년·반·번호는 올해 속성이라 다음 해 새 학년도 시작을 해도 기록이 이어집니다(10장). 초기 비밀번호는 자동으로 만들어져 명단에 보이고, 비밀번호 카드 인쇄로 나눠 주면 학생이 첫 로그인 뒤 자기 번호로 바꿀 수 있습니다. 전학 간 학생은 삭제보다 전출 처리가 기록 보존에 좋습니다.

3새 화면 · 앱처럼 설치 3.0

새 화면은 화면(HTML)을 선생님 시트가 아니라 GitHub 한 곳에서 가져오고, 저장은 지금처럼 선생님 시트에 하는 방식입니다. 화면이 고쳐지면 모든 학교에 저절로 반영되고(라이브러리를 올릴 필요 없음), 태블릿·휴대폰 홈 화면에 앱으로 추가해 주소창 없이 열며, 구글 웹앱 위쪽의 "이 앱은 Google에서 만들지 않았습니다" 띠가 없습니다. 자료는 한 조각도 GitHub로 가지 않습니다 — 화면 파일만 거기서 옵니다.

설정 → 화면 방식 → "새 화면" 저장 → 학생용 주소(QR)로 들어오면 새 화면이 열림 → 로그인 화면 아래 "홈 화면에 앱으로 추가"
▲ 새 화면 학생 로그인 — 학교 주소를 기기에 기억하고, 아래 "다른 학교로 바꾸기"
이런 점이 달라요설명
화면 수정이 저절로버튼 위치·글자·새 메뉴 같은 화면 수정은 GitHub에 올리는 순간 모든 학교에 반영. 앱을 열 때 새 판을 저절로 받습니다(새로고침 요령 필요 없음).
라이브러리는 서버가 바뀔 때만저장·계산 방식(.gs)이 바뀌는 판만 라이브러리를 올립니다. 새 화면이 더 새 기능을 알고 있으면 "라이브러리를 올리면 쓸 수 있어요"라고 안내합니다.
앱처럼 설치안드로이드·PC Chrome: 로그인 화면 아래 "홈 화면에 앱으로 추가". 아이폰·아이패드: 공유 → 홈 화면에 추가. 아이콘 하나로 열리고 여는 속도도 빨라집니다.
주소는 그대로학생용 주소·QR·즐겨찾기는 그대로입니다. 새 화면이 학교 주소를 기기에 기억해 두고, 학교 주소가 바뀌면(11장) 저절로 새 주소로 옮겨 갑니다.
되돌리기설정 → 화면 방식 → 기존 화면, 또는 주소 뒤에 ?classic=1.
판 번호새 화면도 학교 프로그램과 같은 번호(3.3.x)를 씁니다. 설정 → 업데이트 칸에 둘 다 보입니다.
새 화면에서 생긴 것들로그인 새 소식 창(판이 바뀌면 "이번에 바뀐 것"을 한 번) · 세특 초안·새 학년도 시작 메뉴 · 휴대폰에서 위 메뉴를 누르면 첫 화면이 바로 열림 · 카메라 판정기가 앱 안 전체 화면으로 열리고 "앱으로 돌아가기"로 닫힘 · 색깔 매트 놀이터 밝은 화면 · 초기화 한꺼번에 고르기 · 줄넘기 급수·인증서·전국 현황판 화면. 기존 화면을 그대로 쓰는 학교는 이 중 화면 쪽 기능이 보이지 않습니다.
▲ 로그인 새 소식 창 — 판이 바뀌면 이번에 바뀐 것을 한 번 보여 주고, 라이브러리 새 버전이 있으면 적용 방법도 함께

6학생이 들어오는 방법

학생은 태블릿이나 컴퓨터에서 같은 주소(또는 교실에 붙인 QR)를 열고 학년·반·번호를 고른 뒤 숫자판에 비밀번호 4자리를 누릅니다. 5번 틀리면 1분 잠기고, 3분 동안 아무것도 안 하면 자동으로 나갑니다(설정에서 조정). 처음엔 선생님이 준 번호를 쓰고, 들어간 뒤 "비밀번호 바꾸기"에서 자기 번호로 바꿀 수 있습니다.

▲ 학생 줄넘기 화면 — 오늘 목표 링, 횟수 넣기, 카메라로 뛰기, 나의 급수

수행평가 교사 전용

PAPS

카메라 줄넘기 판정기 v0.7.4

전자 줄넘기는 손으로 빙글빙글 돌려도 숫자가 올라가지요. 판정기는 태블릿·노트북·휴대폰 카메라로 관절의 움직임을 읽어 엉덩이와 머리가 같이 뜨고 팔이 돌아갈 때만 1회로 셉니다. 앉아서 팔만 돌리거나 줄 없이 콩콩만 뛰면 세지 않고 화면에 이유가 떠요. 영상은 기기 밖으로 나가지 않습니다.

학생: 오늘 줄넘기 → 종류 고르기 → 카메라로 뛰기 → (앱 안 전체 화면) 시작 → 뛰기 → 끝내고 기록하기 → "카메라 판정" 기록으로 바로 확인 상태 저장

준비 — 줄넘기 설정 → 카메라 판정기에 판정기 주소(기본값 있음), 기록할 최소 횟수, 민감도(6~16, 기본 10). 학생은 민감도를 못 바꿉니다. v0.7부터 밝은 카드 화면, 10회마다 축하, 전체 화면 버튼, 휴대폰 세로 화면에서 내 모습과 횟수가 나란히. 새 화면에서는 판정기가 앱 안 전체 화면으로 열리고 "앱으로 돌아가기"로 닫으면 방금 기록이 바로 보입니다. 카메라가 센 기록은 짝 체크·교사 확인 없이 바로 확인 상태(입력자 "카메라")이고 전국 현황판에도 바로 올라갑니다.

급수 인증 3.1.9

한국줄넘기협회 급수표(흰 → 노랑 → 초록 → 파랑 → 밤 → 주황 → 빨강 → 검은 → 와이어)를 보고 선생님이 항목별로 체크합니다. 한 급수의 항목을 모두 통과하면 그 급수를 딴 것으로 보고, 앞 급수를 못 딴 학생은 잠깁니다(이미 체크된 칸은 해제만).

▲ 급수 인증표 — 반·급수·통과일을 고르고 체크. 이름 옆 "모두"는 그 학생 전체, 머리줄 체크는 항목 전체·반 전체. 저장하면 "급수가 오른 학생"을 알려 줍니다.
  • 급수표 고치기 — "이름 #색상" 한 줄 다음에 "항목, 기준"을 한 줄씩, 급수 사이는 빈 줄. 기준을 비우면 "성공". 이미 체크한 칸은 급수·항목 순서로 남으니 학기 중에는 이름만 고치고 순서는 바꾸지 않는 편이 좋습니다. "기본 급수표로" 되돌릴 수 있습니다.
  • 학생 화면에 나의 급수 — 지금 급수, 다음 도전 급수의 항목별 통과 ✓, 급수 사다리, 우리 반 급수 분포(인원만). 학급 현황에 우리 반 급수(칩을 누르면 명단).
  • 줄넘기 설정에서 급수 인증 사용을 끄거나, 급수 인증 화면의 "학급 현황·학생 화면에 우리 반 급수 보이기"를 끌 수 있습니다. 시트 줄넘기_급수는 첫 인증 저장 때 생기고, 학생을 삭제하면 그 학생의 급수도 함께 지워집니다.

10새 학년도 시작 · 자료 관리

설정 → 새 학년도 시작 → (보관본 자동) 학년도 +1 · 재학생 학년 올리기 · 마지막 학년 졸업 · (고르면) 졸업·전출 학생 정리 → 새 명렬 붙여넣기 → 기존 학생 채우기

새 학년도 시작(3.1)은 예전의 "학년 올리기"를 한 화면에 모은 것입니다. 시작 전에 시트 보관본(사본)을 자동으로 만들고, 학년도를 바꾸고, 재학생 학년을 올리며(마지막 학년은 졸업 처리), 고르면 이미 졸업·전출한 학생을 정리합니다. 끝나면 이어서 할 일(새 명렬 붙여넣기 → 기존 학생 채우기)을 안내합니다. 학생ID는 그대로라 지난 기록이 이어집니다.

자료는 어디에 — 모두 선생님 스프레드시트의 시트(학생, 설정, 수업_*, 평가_*, PAPS_*, 체력_*, 줄넘기_*, MAT_*, FMS_*, 클럽_*, 세특_초안, 숨김 시트 _속성)에 있고, 사진은 선생님 드라이브 폴더에 있습니다. 백업은 파일 → 사본 만들기면 충분합니다. 시트를 직접 고쳤으면 메뉴 캐시 비우기.

11새 버전 적용 — 2분 · "새 배포"는 누르지 마세요

새 버전이 나오면 프로그램이 알아서 알려 줍니다. 선생님이 로그인할 때 새 소식 창과 홈 알림이 뜨고, 설정 → 업데이트 칸에 적용 순서가 나옵니다. 파일을 다시 붙여넣을 필요는 없습니다. 새 화면을 쓰면 화면만 바뀐 판은 아무것도 할 게 없고, 라이브러리(서버)가 바뀐 판만 아래 세 단계입니다.

  1. 스프레드시트 → 확장 프로그램 → Apps Script
  2. 왼쪽 "라이브러리" 아래 PE 를 클릭 → 버전을 알림에 적힌 숫자로 바꾸고 저장 (v3.3.0 은 라이브러리 51)
  3. 오른쪽 위 배포 → 배포 관리 → 연필 ✎ → 버전 "새 버전" → 배포
⚠ "새 배포"는 누르지 마세요업데이트할 때 배포 → 새 배포를 누르면 학생용 주소가 새로 생겨 교실 QR·즐겨찾기가 옛 주소가 됩니다. 반드시 배포 관리 → 연필 → 새 버전으로 하세요. (처음 설치할 때만 새 배포입니다.)

자료도 주소도 그대로입니다. 끝나면 프로그램 화면을 새로 고치면 버전 숫자가 바뀌어 있습니다. 권한이 새로 필요한 판이면 배포 때 "액세스 승인"이 한 번 더 뜨는데 1장과 같이 허용하면 됩니다. 업데이트를 미뤄도 지금 버전이 그대로 돌아가니 급하지 않습니다. 껍데기(Code.gs)는 3.0.0 때 doPost 한 줄이 늘어난 뒤로 그대로입니다 — 2.x에서 올라오는 학교만 첨부 shell/Code.gs 를 한 번 다시 붙여 넣으세요(파일 이름은 Shell.gs 든 Code.gs 든 상관없습니다).

▲ 설정 → 업데이트 칸 — 지금 판·이번 판에서 바뀐 것·지난 판 보기, 그 아래 사용 학교 알림

그래도 주소가 바뀌었다면 3.1.5

기록은 그대로입니다. 선생님이 로그인할 때 "학생용 주소가 바뀌었어요 — QR 다시 인쇄" 알림이 뜨고, 옛 주소(교실 QR·즐겨찾기)로 들어온 사람에게는 "새 주소로 열기" 버튼이 나옵니다. 새 화면을 쓰는 기기는 저절로 새 주소로 옮겨 갑니다. 설정 → 접속 주소에서 QR을 다시 인쇄해 붙이고, 교실 QR을 다 바꾼 뒤 옛 배포는 보관처리하면 됩니다.

12사용 학교 알림 — 제가 아는 것과 모르는 것 3.1.3

설정 → 업데이트 칸 아래에 사용 학교 알림이 있습니다. 하루 한 번 "이 프로그램을 쓰고 있어요" 신호를 만든 선생님께 보냅니다. 기본은 익명이고, 학교 이름도 알리기 / 알리지 않기로 바꿀 수 있습니다.

제가 알 수 있는 것은 이 프로그램을 쓰는 학교 수와 프로그램 정보(어느 판을 쓰는지, 초·중, 켠 모듈 수)뿐이에요. 학교 이름은 '학교 이름도 알리기'를 고른 학교만 알 수 있어요. 학생 이름·기록·비밀번호는 각 학교 선생님의 구글 스프레드시트에만 있어서 저는 볼 수도, 모을 수도 없어요.
왜 모으나요보내는 것 (익명)끄는 방법
새 화면이 GitHub에서 오기 때문에 GitHub 사용량과 서버 확충을 미리 준비하고, 어느 판을 몇 학교가 쓰는지 알아야 업데이트를 꾸준히 이어 갈 수 있어서입니다.무작위 학교 번호 · 판 번호 · 학교급 · 켠 모듈 수 · 화면 방식. "학교 이름도 알리기"를 고르면 학교 이름을 함께.설정 → 업데이트 아래 → 알리지 않기. 끄면 아무것도 보내지 않고 모든 기능은 그대로입니다.

13자주 묻는 질문

Q. 제 자료가 선생님(제작자) 쪽으로 가나요?
A. 아니요. 프로그램 코드만 라이브러리에서 빌려 쓰고, 실행은 선생님 계정에서, 저장은 선생님 시트와 드라이브에만 됩니다. 사용 학교 알림(12장)은 학교 수와 판 정보만이고 끌 수 있으며, 전국 현황판(7장)은 참여를 켠 학교만 가린 이름·횟수를 보냅니다.

Q. 새 화면으로 바꾸면 학생 주소가 바뀌나요?
A. 아니요. 같은 주소·QR로 들어오면 새 화면이 열립니다. 되돌리려면 설정 → 화면 방식 → 기존 화면.

Q. 급수 인증 메뉴를 눌렀더니 "라이브러리 50 이상이 필요해요"라고 나와요.
A. 새 화면이 학교 프로그램보다 앞서 있는 것입니다. 11장대로 라이브러리 버전을 올리면 바로 쓸 수 있습니다.

Q. 전국 현황판에 참여했더니 "학생 입력 자동 확인"이 꺼졌어요.
A. 의도된 것입니다. 참여 중에는 선생님이 확인한 기록과 카메라 기록만 현황판에 올라가야 공정하기 때문에 자동 확인을 켤 수 없습니다. 기록 확인 화면의 "모두 확인"으로 빠르게 확인하세요.

Q. 학생이 구글 계정이 있어야 하나요?
A. 없어도 됩니다. 배포할 때 "모든 사용자"로 했기 때문에 주소만 있으면 열리고, 학생은 프로그램 안의 비밀번호 4자리로 들어옵니다.

Q. 주소를 열면 "스크립트 기능이 완료되었지만 아무것도 반환하지 않았습니다"가 나와요.
A. 라이브러리가 연결되지 않은 상태입니다. 1장 3번(라이브러리 PE 추가)을 확인하고 배포 관리 → 새 버전을 다시 해 주세요. "PE is not defined"면 식별자를 PE 로 고치세요.

Q. 처음 열 때 오래 걸려요.
A. 첫 접속 때 시트 30개쯤을 만들어서 그렇습니다. 한 번 만들어진 뒤로는 2~3초 안에 열립니다.

Q. PAPS 등급이 "기준 없음"으로 나와요.
A. 학교급과 학생 학년이 맞는지 보세요. 초등 1~2학년은 기준표가 없습니다. 학교급을 바꾼 직후라면 메뉴 체육교사 보조 → 캐시 비우기.

Q. 교사 비밀번호를 잊었어요.
A. 스프레드시트 메뉴 체육교사 보조 → 교사 비밀번호 초기화 → 1234.

Q. 시트를 직접 고쳤는데 화면이 그대로예요.
A. 화면이 6시간 동안 시트 내용을 기억합니다. 메뉴 체육교사 보조 → 캐시 비우기.

Q. 사진은 어디에 저장되나요?
A. 시트가 있는 드라이브 폴더 안에 "스포츠클럽 사진·보고서", "건강체력교실 사진·결과물", "줄넘기 짝 확인 사진", "FMS 도전 인증 사진·영상", "색깔 매트 놀이터 그림" 폴더가 생기고 거기에 저장됩니다. 시트에는 파일 ID만 남습니다.

Q. 두 학교(두 시트)에서 쓰고 싶어요.
A. 시트마다 1장을 반복하면 됩니다. 라이브러리는 같은 것을 씁니다.

Q. 오프라인판도 있나요?
A. 있습니다. 인터넷·구글 계정 없이 파일 하나로 도는 판이고 같은 판 번호(3.3.0)를 씁니다. 새 화면·전국 현황판·사용 학교 알림처럼 인터넷이 필요한 것은 빠지고, 급수 인증·인증서·세특 초안·새 학년도 시작은 똑같이 됩니다. 별도 설명서를 참고하세요.
