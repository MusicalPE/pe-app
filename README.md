# pe-app — 체육교사 보조 프로그램 새 화면

v3.0 부터 **화면(html)은 이 저장소의 GitHub Pages 한 곳에서**, 저장은 지금처럼 각 학교 구글 시트 + Apps Script 라이브러리에서 합니다.

- 새 화면: https://musicalpe.github.io/pe-app/?app=<학교 웹앱 …/exec 주소>
  (한 번 열면 이 기기에 학교 주소를 기억합니다. `?page=teacher` 를 붙이면 선생님 탭이 먼저 열립니다.)
- `app.html` — 앱 본체(빌드 결과물). 직접 고치지 말고 라이브러리 html 을 고친 뒤 `node tools/build-web.js` 로 다시 만듭니다.
- `index.html` — 작은 로더. `ready.json` 의 판 번호를 붙여 `app.html?v=판` 으로 보냅니다(새 판이 나오면 바로 새 파일을 받게).
- `ready.json` — `ready: true` 일 때만 학교 설정의 "화면 방식 → 새 화면"을 고를 수 있습니다. `minServerApi` 는 필요한 서버 기능 번호(라이브러리 37 = 1).
- `poc/` — v3.0 0단계 연결 시험 페이지 (보관용).

학생 자료는 이 저장소에 들어오지 않습니다. 화면 파일만 있고, 자료는 각 학교 구글 시트·드라이브에 저장됩니다.

## 사용 조건

이 프로그램과 사용설명서의 저작권은 **음악적체육인**에게 있습니다. 자세한 내용은 [LICENSE](LICENSE) 파일을 봐 주세요.

| 이렇게 쓸 수 있어요 (무료) | 이렇게는 쓸 수 없어요 |
|---|---|
| 학교·교사·학생·교육기관이 교육 목적으로 사용 | 프로그램이나 그 일부를 판매하거나 유료 서비스·연수·자료에 넣기 |
| 자기 학교(학급)에 설치하고 학교에 맞게 고쳐 쓰기 | 광고를 붙여 배포·운영하기 |
| 출처를 밝히고 돈을 받지 않고 다른 선생님과 나누기 | 저작자 표시·사용 조건을 지우거나 자기가 만든 것처럼 배포하기 |

- 학생 명단과 기록은 각 학교의 구글 스프레드시트(드라이브)에만 저장되는 그 학교의 자료입니다.
